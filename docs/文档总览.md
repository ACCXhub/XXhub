# AutoDy 文档总览

## 文档目的与适用状态

本套文档服务于 AutoDy 的安装、维护、测试、发布和后续开发。它以当前 main 分支的实现和已完成验证为依据：AutoDy 1.4.2 是发布候选，等待最终 Release CI 通过；v1.4.0 与 v1.4.1 已存在，不能移动既有标签。文档中的“已实现并验证”只指向代码、测试或完成的本地验证；“已实现，等待最终发布 CI”不等价于已发布；“后续规划”不应被当作当前能力。

## 文档地图

| 文档 | 主要用途 | 阅读后应能回答的问题 |
| --- | --- | --- |
| 01-软件需求规格说明书 | 定义问题、需求、边界和验收条件。 | 产品必须做什么，哪些情形必须停止？ |
| 02-系统设计说明书 | 解释本机服务、托盘、浏览器与安装器如何协作。 | 为什么服务会复用、端口如何安全回退？ |
| 03-安装部署与用户手册 | 指导下载、安装、启动、升级、修复和卸载。 | 用户应如何操作，预期结果不出现时怎么办？ |
| 04-测试与验收报告 | 汇总可审计的测试证据和发布门禁。 | 哪些结果已验证，最终还缺什么？ |
| 05-运维维护与故障排查 | 给出安全、可执行的诊断和恢复步骤。 | 如何排障而不误杀进程或删除资料？ |
| 06-隐私与安全设计 | 说明数据边界、包完整性和已知风险。 | 哪些数据受保护，哪些位置禁止流转？ |
| 07-项目交接说明 | 为下一位开发者保留当前状态与操作清单。 | 接手后第一小时应做什么？ |
| 08-v1.4.2发布说明 | 面向用户概述候选版本的变更与限制。 | 候选版本带来什么，何时可以安装？ |

## 推荐阅读顺序

普通用户先读 03，再读 08 中的安装选择和校验说明；遇到问题转到 05。测试人员先读 04，必要时对照 01 的验收条件和 06 的隐私边界。开发与发布人员先读 07，随后读 02、04、06，最后核对 08。任何涉及真实账号、浏览器资料或消息的操作都必须先理解 06 的边界。

## 文档状态与维护责任

README 负责 GitHub 项目入口；CHANGELOG 负责历史版本差异；本目录的中文文档负责工程交付内容。英文文件仅在 GitHub、构建、Release 工作流或项目规则要求的路径上作为兼容入口存在，不再承载重复正文。修改服务身份、端口、安装目录、数据保留、发布包、日志导出或浏览器安全逻辑时，提交者必须同步审阅 01、02、03、04、05、06、07、08 的相关段落。

更新文档时应先找到支持证据，再选择准确状态标记；禁止通过复制通用文字扩充篇幅。不得写入真实账号、目标、消息、Cookie、认证令牌、浏览器 profile 内容、日志或机器私有目录。文中使用 %LocalAppData%\AutoDy、D:\AutoDy、127.0.0.1:<selected-port>、<ProductCode> 和 <日志路径> 等可移植占位符。
