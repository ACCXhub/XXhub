# AutoDy 文档总览

## 文档目的与当前状态

本套文档服务于 AutoDy 的安装、维护、测试和长期维护。当前稳定版本为 v1.5.0，它发布已验收的 watchdog、服务生命周期、稳定好友绑定、Friends/Overview 一致性和 UI 可靠性改进，并保持既有 standalone MSI/Portable 与安全边界。

## 推荐阅读顺序

普通用户先读 README 和 03，遇到问题再读 05。维护人员先读本总览、`docs/codex/PROJECT_HANDOFF.md`、02 和 06，再按改动范围查看 01 与 04。历史计划只在追溯旧决策时阅读，不应作为当前执行清单。

## 维护原则

README 负责公开项目入口，CHANGELOG 负责历史，RELEASE_NOTES 负责当前发布，`docs/codex/PROJECT_HANDOFF.md` 负责代理维护状态。修改服务身份、端口、Scheduler、安装目录、数据保留、发行包或浏览器安全逻辑时，应同步审阅对应当前文档。

文档不得写入真实账号、目标、消息、Cookie、认证令牌、浏览器 profile、原始日志或机器私有目录。可移植示例使用 `%LocalAppData%\AutoDy`、`D:\AutoDy`、`127.0.0.1:<selected-port>` 和 `<日志路径>` 等占位符。
