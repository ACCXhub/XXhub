# AutoDy 安装部署与用户手册

这份手册按“下载 → 安装 → 登录 → 加好友 → 配文案 → 定时 → 查看结果 → 卸载”的顺序写。普通使用不需要安装 Python、Node.js 或 Playwright。

## 1. 适用版本

本手册对应 **AutoDy 1.5.4 / Windows x64**。

普通用户使用：

```text
AutoDy-Setup-1.5.4.exe
```

MSI、Portable、SHA-256 和 `release-manifest.json` 也会随同一 GitHub Release 提供。v1.4.4 是上一稳定升级基线；v1.5.0–v1.5.3 不作为当前安装来源。

## 2. 下载

只从项目 GitHub Releases 下载：

```text
https://github.com/ACCXhub/XXhub/releases
```

普通用户只需要下载：

```text
AutoDy-Setup-1.5.4.exe
AutoDy-Setup-1.5.4.exe.sha256
```

想自己核对文件时，在下载目录打开 PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 '.\AutoDy-Setup-1.5.4.exe'
```

把输出与 `.sha256` 文件中的值对上即可。

> 当前安装包未做商业代码签名时，Windows 可能显示“未知发布者”或 SmartScreen 提示。这与文件 SHA-256 是否匹配是两件事。

## 3. 安装

### 最简单的安装方法

1. 双击 `AutoDy-Setup-1.5.4.exe`。
2. Windows 询问是否允许修改设备时，确认你运行的是刚下载并校验的 AutoDy 安装器，然后选择允许。
3. 按安装界面继续。
4. 默认安装位置优先是：

```text
D:\AutoDy
```

如果 D: 不可用，会使用：

```text
%LOCALAPPDATA%\Programs\AutoDy
```

5. 安装完成后，从桌面或开始菜单打开 AutoDy。

### 数据放在哪里

程序目录和用户数据是分开的。

程序通常在：

```text
D:\AutoDy
```

用户数据在：

```text
%LOCALAPPDATA%\AutoDy
```

里面可能包含配置、运行历史、受管浏览器资料等。普通升级、Repair 和卸载默认不会清空这些数据。

## 4. 第一次打开

正常情况下：

1. 双击 AutoDy 桌面快捷方式或开始菜单入口。
2. 托盘程序启动本机 AutoDy 服务。
3. 浏览器打开本机 Dashboard。
4. 第一次使用 Douyin 时，AutoDy 会打开自己的受管 Chromium。
5. 在这个受管 Chromium 中完成登录。

不要把日常浏览器 Cookie/profile 手工复制到 AutoDy。

如果 8765 端口被别的程序占用，AutoDy 会尝试 8766–8799，不需要手工抢端口。

## 5. 添加续火好友

1. 打开 Dashboard 的“好友管理”。
2. 点击扫描/刷新好友。
3. 找到目标好友。
4. 选择加入续火。
5. 如果旧绑定失效，按页面提示执行“重新关联”。

AutoDy 会使用稳定好友身份、账号范围和当前会话定位来确认目标。遇到同名、扫描不完整或身份无法确认时，会要求重新处理，而不是只按昵称猜。

## 6. 添加文案

### 单条/文案库

进入“文案库”，维护你要发送的内容。

### 文案包

进入“文案包”可以：

- 使用默认文案包；
- 新建自己的文案包；
- 给某个好友单独指定文案包；
- 使用 `one_for_all` 时，让当天所有目标和重试复用同一条 canonical 文案。

## 7. 设置自动任务

1. 打开“定时任务”。
2. 设置每日续火时间。
3. 按需启用每日/每周健康检查。
4. 保存。
5. Windows 出现 UAC 时，只在 AutoDy 正在应用 Scheduler 配置时确认。

自动任务由 Windows Task Scheduler 管理，因此关掉 Dashboard 页面不等于取消定时任务。

## 8. 看今天有没有发送成功

主要看“总览”和“运行日志”。

常见状态：

| 状态 | 你要做什么 |
| --- | --- |
| `completed` / 已完成 | 不用处理 |
| `already_done` | 今天已有可靠完成证据，不会重复发 |
| `retry_pending` | 等待有界安全重试 |
| `recovered` | 后续安全重试已成功 |
| `final_failed` | 打开失败详情处理 |
| `uncertain` / 待核实 | 先诊断，不要直接重复发送 |
| `cancelled` | 根据取消原因决定是否重新运行 |

`uncertain` 表示系统无法可靠证明“已发送”还是“未发送”。此时 AutoDy 会停止自动补发，避免重复消息。

## 9. 一键诊断与修复

出现“待核实”、绑定异常或当天状态不一致时，可以使用现有“一键诊断与修复”。

它会先做只读核验：

- 已确认今天发送过：跳过；
- 已确认今天没发送：才进入原有安全发送链；
- 无法确认：继续保持停止，不盲发。

## 10. 多账号

每个账号有自己的目标、计划、受管浏览器 profile 和运行状态。

切换账号前，先等正在进行的真实发送、dry-run 或其他受管浏览器操作结束。退出账号后，旧好友绑定需要重新验证。

## 11. Repair / 升级

### Repair

如果程序文件、快捷方式或安装期 Scheduler 配置损坏，可以通过 Windows Installer Repair 修复。Repair 默认保留 `%LOCALAPPDATA%\AutoDy`。

### 从 v1.4.4 升级到 v1.5.4

使用正式 Release 中的 `AutoDy-Setup-1.5.4.exe`。底层 canonical MSI 负责 1.4.4 → 1.5.4 的 Windows Installer 升级生命周期，用户数据保持独立。

较老的 1.4.0–1.4.2 属于旧 per-user 安装范围，检测到时先按安装器提示正常卸载旧程序，再安装 1.5.4；DataRoot 默认保留。

## 12. 卸载

你可以任选一种方式：

### 方法 A：直接点卸载程序

打开 AutoDy 安装目录，双击：

```text
Uninstall AutoDy.exe
```

### 方法 B：开始菜单

打开：

```text
开始菜单 → AutoDy → 卸载 AutoDy
```

### 方法 C：Windows 设置

打开：

```text
设置 → 应用 → 已安装的应用 → AutoDy → 卸载
```

### 卸载时会发生什么

普通卸载会移除：

- AutoDy 程序文件；
- 桌面/开始菜单快捷方式；
- Windows Installer 产品注册；
- AutoDy Windows Tasks。

`Uninstall AutoDy.exe` 会询问是否同时删除用户数据。

**默认选择是保留用户数据。**

只有当你明确确认删除时，才会清理：

```text
%LOCALAPPDATA%\AutoDy
```

如果以后还想重装并保留配置，卸载时不要删除用户数据。

## 13. Portable

技术用户可以下载：

```text
AutoDy-Windows-Portable-1.5.4.zip
```

完整解压后，从解压目录顶层运行 `AutoDy.cmd`。不要直接在 ZIP 内运行。

Portable 与安装版同时存在时，不要让两个实例同时控制同一套 Douyin browser workflow。

## 14. 常见问题

| 问题 | 先做什么 |
| --- | --- |
| Dashboard 没打开 | 从 AutoDy 桌面/开始菜单入口重新打开 |
| 8765 被占 | 让 AutoDy 自动选择 8766–8799 |
| 登录过期 | 在 AutoDy 受管 Chromium 中重新登录 |
| 好友要求重新关联 | 重新扫描后按“重新关联”操作 |
| 显示“待核实” | 用“一键诊断与修复”做只读核验 |
| 定时任务不生效 | 查看 Scheduler/UAC/运行日志 |
| 安装或 Repair 失败 | 先校验安装包 SHA-256，再保存安装日志 |
| 想彻底删除所有数据 | 通过 `Uninstall AutoDy.exe` 卸载并明确选择删除用户数据 |

更深入的故障处理见 [11-运维维护与故障排查](11-运维维护与故障排查.md)。
